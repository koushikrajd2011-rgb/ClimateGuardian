# 🌍 Climate Guardians

A HTML5 tower defense game about fighting climate change. Place eco-towers to stop pollution enemies!

## Quick Start

Open `index.html` in any browser. That's it.

## Files

```
index.html          ← Main game
config.js           ← Game data
maps.js             ← 20 maps
game.js             ← Game engine
*.png               ← sprites 
```

## How to Play

- Enemies follow the **grey road** — towers can't go on it
- Place towers **anywhere else**, even during waves
- Click towers to sell/upgrade
- Waves per level = zone number (Zone 1 = 1 wave, Zone 8 = 8)

Towers use **emoji** 

## Controls

| Key | Action |
|---|---|
| Space | Start wave |
| Escape | Deselect |
| Right-click | Cancel placement |
